# Aplikasi Perpustakaan Sekolah

Project web perpustakaan berbasis PHP Native untuk mengelola data anggota, buku, transaksi peminjaman, dan kunjungan siswa.

## Fitur Utama
- **Admin**: Kelola buku, anggota, transaksi, dan melihat laporan kunjungan.
- **Siswa**: Pendaftaran, melihat daftar buku, pinjam buku, dan presensi.

## Cara Instalasi
1. Clone repository ini atau download sebagai ZIP.
2. Masukkan folder project ke dalam `htdocs` (jika menggunakan XAMPP).
3. Import database SQL ke phpMyAdmin.
4. Sesuaikan konfigurasi database di folder `config`.
